=====================================================
PYTHON PROGRAMMING: OVERVIEW & KEY CONCEPTS
=====================================================

1. WHAT IS PYTHON?
- Created by Guido van Rossum and released in 1991.
- High-level, interpreted, dynamically-typed programming language.
- Emphasizes code readability and clean syntax using indentation instead of curly braces.
- Follows the philosophy outlined in "The Zen of Python" (import this): "Simple is better than complex."

2. KEY FEATURES
- Interpreted: Code executes line-by-line, eliminating manual compilation steps.
- Dynamically Typed: Variable types are determined at runtime without explicit declarations.
- Multi-Paradigm: Supports Procedural, Object-Oriented (OOP), and Functional programming styles.
- Automatic Memory Management: Built-in garbage collector handles allocation and cleanup.
- Cross-Platform: Runs on Windows, macOS, Linux, and Unix systems.

3. CORE DATA STRUCTURES
- Primitive Types: int, float, bool, str.
- Lists: Ordered, mutable collections of items (e.g., [1, 2, "apple"]).
- Tuples: Ordered, immutable collections (e.g., (1, 2, 3)).
- Dictionaries: Key-value hash maps (e.g., {"name": "Alice", "age": 25}).
- Sets: Unordered collections of unique elements (e.g., {1, 2, 3}).

4. FUNCTIONS & MODULARITY
- Defined using the `def` keyword, supporting default values, *args, and **kwargs.
- Supports lambda expressions (anonymous single-line functions).
- Code reuse via modules (.py files) and packages (directories with __init__.py).

5. OBJECT-ORIENTED PROGRAMMING (OOP)
- Classes act as blueprints defined using the `class` keyword.
- The `__init__` constructor initializes object state.
- Supports inheritance, polymorphism, and encapsulation through naming conventions.

6. POPULAR ECOSYSTEMS & USE CASES
- Artificial Intelligence & Machine Learning: PyTorch, TensorFlow, Hugging Face, Scikit-learn.
- Agentic AI & LLMs: LangChain, LangGraph, LlamaIndex, MCP.
- Data Analysis & Science: NumPy, Pandas, Matplotlib, Polars.
- Web Development: FastAPI, Django, Flask.
- Automation & Scripting: Web scraping (BeautifulSoup, Playwright), file operations, task schedulers.

7. PACKAGE MANAGEMENT & ENVIRONMENTS
- Standard package installer: pip.
- High-performance package manager: uv.
- Dependency tracking: requirements.txt or pyproject.toml.
- Virtual environments: `python -m venv .venv` isolates project dependencies.

8. STRENGTHS & LIMITATIONS
- Strengths: Rapid development speed, massive community, rich third-party library ecosystem.
- Limitations: Slower execution speed compared to compiled languages (C++/Rust); Global Interpreter Lock (GIL) limits true multi-core CPU threading in standard CPython.
